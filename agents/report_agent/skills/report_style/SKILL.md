# 报告风格规范（report_agent 专属）

## 结构要求

- 标题层级只用两级（`#` 与 `##`），不再下探。
- 每个章节先给一句话结论，再给支撑明细。
- 列表一律用无序列表；数字仅在表达数量时使用。

## 措辞要求

- 用短句与主动语态；避免"可能/大概"等模糊词，不确定就标注 `[待确认]`。
- 风险描述必须包含：现象、影响面、建议动作三要素。

## 交付要求

- 正文不超过 400 字；超出部分移入附录。
- 文件名遵循 `weekly_report_<week>.md` 约定。
