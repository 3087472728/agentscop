# 数据质检

## 何时使用

用户要求检查、审核、验证某个数据文件（JSON/CSV/Markdown 表格等）的质量时使用。

## 质检清单（逐项执行并在结论中逐项回答）

1. **可读性**：文件能否正常解析？编码是否为 UTF-8？
2. **完整性**：必填字段/列是否齐全？空值集中在哪些位置？
3. **一致性**：同类字段的类型/单位/命名是否一致（如日期格式混用）？
4. **取值合理性**：数值是否越界、日期是否未来时、枚举值是否合法？
5. **重复**：是否存在重复记录/重复主键？

## 输出格式

结论必须包含：总体判定（通过 / 有条件通过 / 不通过）、逐项结果表、
问题清单（按严重度排序：阻断 > 警告 > 建议）、修复建议。

## 约束

- 只读检查：不得修改被检数据文件；如需修复样本另存副本。
- 结论必须基于实际读到的内容，禁止臆测未读取的部分。
