# 技能分发探针（sync_probe）

## 何时使用

- 用户要求验证技能系统/技能同步是否生效；
- 用户要求运行"测试技能"、"探针"；
- 排查"技能列表里看得到但用不了"的问题。

## 操作步骤

1. 用 Glob 工具找到探针脚本（它随本技能一起分发，位于本技能目录下）：
   - 匹配模式：`**/sync_probe/scripts/probe.py`
2. 用 Bash 在工作区当前目录执行（把 `<找到的路径>` 替换为第 1 步的结果）：
   ```bash
   python "<找到的路径>" --out skill_probe_result.txt
   ```
3. 用 Read 工具读取生成的 `skill_probe_result.txt`，向用户报告其中的
   触发时间与结论。

## 预期结果

工作区根目录出现 `skill_probe_result.txt`，内容包含
`技能分发链路 OK` 与触发时间。缺文件或脚本报"not found"即说明分发链路有问题。

## 注意

- 结果文件写在工作区根目录，不要写进本技能目录内部。
- 本技能仅用于链路验证，产出文件可随时删除。
